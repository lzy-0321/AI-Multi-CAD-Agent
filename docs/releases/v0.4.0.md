# Multi-CAD v0.4.0 — selected-part editing / 按 part 局部修改

This version adds source-preserving 3MF import, slicer roles and plate membership, explicit instance selection, geometry-based bounded routing, Blender transforms/cylindrical cuts and SolidWorks plate/washer reconstruction. The eight public MCP entry points remain compatible; discover new operations with backend `project`.

本版增加保留源文件的 3MF 导入、切片类型与打印板归属、明确实例范围、基于几何的限定路由、Blender 变换／圆柱切孔，以及 SW 平板／垫圈重建。仍保持八个公共 MCP 入口，通过 `project` 后端按需发现新操作。

Versions commit only after reopening and validation. Unselected geometry and placement are compared, source negatives remain editable cutters, and mixed projects keep SW native files authoritative with derived mesh previews. Editing selected parts does not rebuild the entire input.

版本在重开验证后才登记，比较未选对象的几何与位置；源负体积保留为可编辑切除体，混合项目保留 SW 原生主文件及派生网格预览，不重建整个输入。

Use `MultiCAD-0.4.0-windows.zip` and its `.sha256` file. Read `QUICKSTART.md` and `PARTS.md` in the archive. Separately installed SW compatibility hosts may need an explicit backend update with the new wheel. Blender safe mode is never disabled automatically.

使用具名 ZIP 与校验和，阅读包内中英文快速指南与局部修改指南。独立安装的 SW 兼容宿主可能需要使用新 wheel 明确更新。不会自动关闭 Blender 安全模式。

Limits: axis-aligned simple SW profiles only; one identified hole for diameter edits; no arbitrary reverse engineering, assembly inference, slicer 3MF write-back or automatic conversion of edited Blender meshes back into SW. Second-machine CAD validation is deferred at the user's request. See the v0.4 validation record for measured coverage.

限制：SW 仅覆盖轴对齐的简单轮廓；改孔径要求唯一已识别孔。不包含通用逆向、装配推断、切片 3MF 回写，或自动把 Blender 编辑后的网格再转换为 SW。按用户要求跳过异机 CAD 验证，实测覆盖见 v0.4 验收记录。
