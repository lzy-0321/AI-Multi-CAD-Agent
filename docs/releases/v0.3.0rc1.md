# Multi-CAD v0.3.0rc1 — Windows candidate / Windows 候选版

## Download / 下载

Download **MultiCAD-0.3.0rc1-windows.zip** and its `.zip.sha256` file from the release assets. GitHub's automatic “Source code” archives are for development, not the ready-to-install bundle. The standalone wheel is also attached for advanced users.

请下载附件中的 **MultiCAD-0.3.0rc1-windows.zip** 及 `.zip.sha256` 校验文件。GitHub 自动生成的 “Source code” 是源码压缩包，不是安装包；单独的 wheel 供高级用户使用。

Requires Windows, 64-bit Python 3.11+, and internet access. CAD must be installed and licensed separately. Git is needed only when downloading an upstream MCP backend. No extra model API key is required.

需要 Windows、64 位 Python 3.11+ 和网络。CAD 软件及许可证需自行准备；下载上游 MCP 时还需 Git。无需额外模型 API Key。

After extracting the ZIP / 解压后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Then follow the bundled `QUICKSTART.md` or `QUICKSTART.zh-CN.md` to configure CAD paths, reuse existing MCPs and export the unified Agent entry.

随后按包内英文或中文快速指南配置 CAD 路径、复用已有 MCP，并导出统一 Agent 入口。

## Changes / 更新

- Versioned, isolated Python installation with a stable launcher, configuration backups and rollback. 无需源码目录的独立安装、固定启动入口、配置备份及回滚。
- `setup --repair` previews changes before saving; `doctor --report` produces a shareable report without raw arguments, environment values or model content. 新增修复预览和脱敏诊断报告。
- Reuses pinned Blender and SolidWorks MCPs. Backend configuration is activated only after installation and handshake checks succeed. 继续复用固定版本上游 MCP，安装及握手成功后才切换配置。
- Eight unified MCP tools retain on-demand operation discovery and no automatic replay of writes. 保持 8 个统一入口、按需工具发现和写入失败不盲目重放。

## Verification and limits / 验证及限制

Local isolated installation and real SolidWorks acceptance passed: create a 120×80×5 mm plate with four 6 mm holes, change only their diameter to 8 mm in a new process, and reopen/verify in a third process. Original files are preserved. Source-free loading was checked from the installed environment, and Chinese/space paths were exercised.

本机隔离安装及真实 SolidWorks 验收通过：创建 120×80×5 mm 四孔底板，第二进程将孔径 6 mm 改为 8 mm，第三进程重开核验；保留原版本。已验证从安装环境加载程序以及中文、空格路径。

Release CI runs automated tests and clean install / upgrade / failure / rollback checks on Windows without starting CAD. The attached `installation-acceptance.json` records these installer checks, not CAD geometry verification.

发布 CI 在 Windows 上执行自动测试，以及安装、升级、失败保护和回滚检查，不启动 CAD。附件 `installation-acceptance.json` 是安装流程证据，不代表 CAD 几何验收。

**本机隔离测试通过，异机实测待完成。** This is a pre-release; real CAD acceptance on a second computer is pending. Blender add-on enablement still needs to match the selected Blender version. General reverse engineering, arbitrary text modeling and automatic assembly are not implemented.

这是预发布候选版。Blender 插件仍需在选定版本中启用；通用逆向、任意文字建模和自动装配尚未实现。安装不包含 CAD，也不自动创建零件。
