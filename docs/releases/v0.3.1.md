# Multi-CAD v0.3.1 — Windows release / Windows 正式版

## Release correction / 发布修正

This release fixes the v0.3.0 tag/package mismatch. The package version, Git tag and downloadable assets now consistently use **0.3.1**. The previous public release is preserved. Stable versions are published as GitHub Releases; versions with `rc` remain pre-releases. Mismatches still fail validation with both the actual and expected versions shown.

本版修复 v0.3.0 标签与候选版包不一致的问题。包版本、Git 标签和附件名称统一为 **0.3.1**，保留旧发布记录。正式版本发布为 GitHub Release，带 `rc` 的版本仍发布为 Pre-release；版本不一致时继续阻止发布，并显示实际值和预期值。

## Download and install / 下载与安装

Download **MultiCAD-0.3.1-windows.zip** and **MultiCAD-0.3.1-windows.zip.sha256** from Assets. The standalone wheel is for advanced users. GitHub's automatic source archives are not the installer bundle.

请从 Assets 下载 **MultiCAD-0.3.1-windows.zip** 及 **MultiCAD-0.3.1-windows.zip.sha256**。单独 wheel 供高级用户使用；GitHub 自动生成的源码压缩包不是安装包。

Requires Windows, 64-bit Python 3.11+ and internet access. CAD software and licensing are separate. Git is needed when installing upstream MCPs. No additional model API key is needed.

需要 Windows、64 位 Python 3.11+ 和网络；CAD 与许可证需自行准备。安装上游 MCP 时需要 Git，无需额外模型 API Key。

After extracting / 解压后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Follow `QUICKSTART.md` or `QUICKSTART.zh-CN.md` in the ZIP. Install into the same directory to upgrade; the stable Agent launcher stays unchanged. `launch.ps1 rollback` restores the prior installation and configuration without reverting CAD project files.

按 ZIP 内中英文指南配置。安装到同一目录即可升级，Agent 固定入口保持不变。`launch.ps1 rollback` 可恢复上一程序版本与配置，不回退 CAD 工程文件。

## Verification and limits / 验证及限制

The release workflow runs tests on Windows with Python 3.11 and 3.14 and verifies clean installation, upgrade, dependency-failure protection and rollback before uploading assets. The attached `installation-acceptance.json` records installation checks, not CAD geometry checks.

工作流在 Windows 上分别使用 Python 3.11、3.14 测试，并在上传附件前验证安装、升级、依赖失败保护和回滚。附件 `installation-acceptance.json` 记录安装检查，不代表 CAD 几何验收。

The existing real SolidWorks acceptance covers a 120×80×5 mm four-hole plate, diameter changes from 6 to 8 mm, and reopen verification in separate processes. CAD implementation is unchanged in this release. General reverse engineering, arbitrary modeling and automatic assembly remain unimplemented. Blender add-on enablement must match the selected installation.

已有真实 SolidWorks 验收覆盖 120×80×5 mm 四孔底板、孔径 6→8 mm 修改及独立进程重开核验；本版未改动 CAD 实现。通用逆向、任意建模和自动装配尚未实现，Blender 插件需在选定版本中启用。

**本机隔离测试通过，异机 CAD 实测待完成。** Formal release status does not imply validation against every CAD version or a completed second-machine CAD test.
