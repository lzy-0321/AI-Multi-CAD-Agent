# v0.2 验证记录

验收日期：2026-10-22（Australia/Sydney）。以下是当前机器的证据，不代表所有 SolidWorks/Blender 版本均通过测试。

## 已验证

- 自动测试 23 项全部通过，覆盖配置迁移与合并、MCP 协议、超时后禁止重放、参数映射和文件版本保护。默认用户配置下再次重开底板复验通过。
- 使用上游 SolidWorks MCP 提供的草图、标注、拉伸、重命名、保存、打开、修改参数工具。
- 创建 120×80×5 mm 底板，四孔中心 (10,10)、(110,10)、(110,70)、(10,70) mm，直径 6 mm。草图完全约束、一个实体、体积 47434.513322353836 mm³，保存并重开通过。
- 第二个独立 MCP 进程从工作副本将四孔改为 8 mm，保护其他参数，新版本体积 46994.690350851255 mm³，与解析计算值误差小于 0.01 mm³。
- 第三个进程重新打开验证，尺寸、孔位、孔径、实体数、约束状态和参数映射通过。原版本 SHA-256 保持不变。
- 网关真实 stdio initialize、tools/list、工具搜索和单项 schema 查询通过；Blender 与 SolidWorks 均通过实际只读调用。

机器本地证据：`runs/plate-validated/project.json`、`runs/plate-validated/reports/`、`runs/gateway-measurement.json`。工程文件为 `runs/plate-validated/output/plate-v001.SLDPRT` 与 `plate-v002.SLDPRT`。这些文件不提交到源码仓库。

## 上下文大小

统一网关暴露 8 个工具。测试时 SolidWorks 宿主提供 96 个工具（95 个上游工具加 1 个精确验收查询）。完整上游 schema 为 80325 个 JSON 字符；网关 schema 加一个所需操作的 schema 为 5385 个字符，减少约 93.3%。这是同一序列化口径下的字符量，不是实际模型 token 消耗；不同 Agent 的工具发现机制会影响收益。

## 已发现并修复的问题

- 两点智能尺寸可能创建斜向距离，导致孔心移动；配方改用圆心到水平/垂直边的尺寸，仍调用上游标注工具。
- 工作流封装参数名与工具的 `name` 参数冲突；更正封装名称并增加文档生命周期回归测试。
- MCP 子进程默认不会继承所有环境变量；测试客户端显式传递数据目录环境。
- 写入超时后先阻止后续写入，再处理连接；重连前等待旧会话清理完成，避免异常清理时序绕过明确的待核对状态。

## 限制

底板是限定配方，不能替代通用参数化逆向或任意装配。新机器的实际软件版本、许可证、模板、权限仍需本机 live 验证。多路径配置测试使用临时目录模拟，不是两台物理电脑实测。

已安装上游源码未修改；可选兼容宿主在运行时提供精确读回、模板路径与尺寸弹窗兼容。普通后端可以直接接入网关，底板高层验收需要该精确读回能力。自带安装器的全新机器在线安装尚未在第二台电脑端到端验证。
