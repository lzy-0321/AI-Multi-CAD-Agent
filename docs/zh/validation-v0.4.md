# v0.4 本机验收 — 2026-10-27

环境：Windows、Python 3.14、Blender 5.2.2 LTS、SolidWorks 2025。通过新建 stdio 网关进程调用现有固定版本的 Blender／SW MCP。Blender 使用专用验收会话，每个建模任务另开后台 Blender。私人源模型、安装路径、原生输出和详细日志均不提交 Git。

## 实测结果

| 场景 | 证据 |
|---|---|
| 真实时钟样本 | 12 个打印板记录、27 个普通及 8 个负体积 part 实例；这是源类型清单，不代表有 35 个产品零件。 |
| 真实抽屉样本 | 13 个打印板记录、29 个普通 part 实例；没有几何符合本轮限定 SW 识别器。 |
| 时钟单 part 移动 | 指定对象移动 1 mm；保存重开后，其余对象的原始／计算几何、分组身份和变换全部匹配。 |
| 时钟负体积 | 已识别圆柱切除体改为 6 mm；检查产品封闭性、圆柱孔壁及孔内无残留材料。产品携带切除体缩放后，再于新进程改为 7 mm，也通过检查。 |
| 抽屉多 part 移动 | 两个目标移动 1 mm，其余 27 个实例保持不变；BLEND 保存重开通过。 |
| 真实来源 SW 重建 | 时钟中的小矩形 part 重建为完全定义草图，厚度改为 0.3 mm；场景中仅替换该对象的派生预览，其余对象不变。 |
| 合成 SW 垫圈 | 两实例中仅一个重建为 12 mm 孔；另一进程改为 14 mm 孔、4 mm 厚；第三个进程重开 SW，核验几何和全部持久参数。另一实例保持不变。 |
| 混合场景与 Blender 续改 | 另一个网格垫圈增加偏心 4 mm 圆柱孔，再在新进程中沿 Z 缩放 1.1 倍，切除体随动。已有 SW 工程和另一实例不变，目标 STL 导出通过封闭性及毫米单位检查。 |
| 预览 | 选中的时钟产品渲染为本地 PNG，已查看图片；图片仅作为补充，不替代尺寸验收。 |

SW 重建检查一个实体、完全约束草图、持久尺寸、解析体积和圆柱位置／半径；矩形轮廓额外检查精确顶点边界。源拟合检查匹配端盖、边界环、圆拟合／弦误差及体积。这属于限定解析检查，不是任意网格的通用 Hausdorff 比较或自交证明。

## 回归与安装

自动测试覆盖源文件保留、实例歧义、声明的切片类型、合成 Orca 风格打印板元数据、未知辅助类型、不完整几何、参数输入、清单篡改、写失败不重放、多目标失败不提交、八入口兼容、原底板生命周期与安装恢复。合成 Orca 元数据测试不代表所有 Orca 版本均已兼容。

Windows ZIP 独立验收另行检查中文和空格目录安装、源码目录外运行、安装环境包位置、升级、依赖失败保护、其他 Agent 配置、原文件保留及回滚。安装器不启动 CAD；本地 `installation-acceptance.json` 与安装包校验和绑定。

按紧凑 JSON 字符量测量：96 个 SW schema 共 76,062 字符；八个网关 schema 为 3,799 字符；网关加一个 part 编辑 schema 为 5,088 字符。后一比较约减少 93.3% 字符，不是实际模型 token 测量。

## 保留的限制

- 按用户要求未做异机 CAD 验收；本次本机未另跑 Python 3.11 CAD 验收。
- SW 仅支持源几何轴对齐的简单轮廓与刚性源变换；缩放／剪切放置、未解析源布尔及复杂抽屉主体会拒绝。
- 用户外部修改原生文件会由哈希发现；映射含糊时停止。尚未实现任意外部 SLDPRT 的自动识别。
- 通用装配、任意雕刻、图片建模、切片设置回写和 Blender 编辑后自动重新分析转 SW 尚未实现。
- 真实验收只使用本次拥有的文档；其他已打开文档的清理保护由生命周期测试覆盖，不冒称另做过真实多用户测试。
- 本记录描述 v0.4.0 的本机 CAD 验收；GitHub CI 独立验证发布安装包，保留此前的 v0.3.1 发布。
